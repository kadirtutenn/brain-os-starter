# Deterministic Learning Contract

Internal learning is limited to evidence-backed operational signals: retrieval
counts, explicit useful-ref feedback, verified outcomes, repeated co-activation,
fingerprint savings, and failed or unused retrieval paths.

The runtime may create structured Insight candidates with sample counts,
confidence, suggested action, and evidence refs. It must not semantically rewrite
those candidates into Lessons or Skills. An external agent or human performs
semantic promotion through the normal gated write path.
