# Memory Contract

The Brain Store is durable, human-readable shared memory. OKF Markdown metadata
is the sole durable authority. Runtime databases, caches, usage counters, and
context receipts can always be discarded and rebuilt.

Durable namespaces include Projects, Agents, Knowledge, Lessons, Skills,
Insights, and compressed Sessions. Observable facts and verified workflows may
be stored; hidden chain-of-thought must not be stored.

Curated fingerprints are durable authored knowledge. Deterministic fingerprints
are rebuildable projections and never replace curated content silently.
